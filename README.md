# tuition-platform

Tuition platform — বাংলাদেশের অভিভাবক ও শিক্ষার্থীদের সাথে যাচাইকৃত টিউটরদের সংযোগের একটি সম্পূর্ণ টিউশন মিডিয়া প্লাটফর্ম।

## বৈশিষ্ট্য

- **হোম পেজ** — হিরো, বিষয়/শ্রেণি/এলাকা/বাজেট দিয়ে খোঁজা, সেরা টিউটর
- **টিউটর তালিকা** — লাইভ সার্চ ও ফিল্টার (বিষয়, শ্রেণি, এলাকা, সর্বোচ্চ ফি), রেটিং ও মাসিক ফিসহ কার্ড
- **টিউটর প্রোফাইল** — শিক্ষাগত যোগ্যতা, অভিজ্ঞতা, ফি, ফোন নম্বর ও শিক্ষার্থীদের রিভিউ (মডাল ভিউ)
- **টিউটর চাই** — শিক্ষার্থী/অভিভাবকের অনুরোধ ফর্ম (শ্রেণি, বিষয়, এলাকা, বাজেট, পছন্দের সময়)
- **টিউটর নিবন্ধন** — নতুন টিউটরের রেজিস্ট্রেশন ফর্ম, জমা দিলে প্রোফাইল তালিকায় যুক্ত হয়
- **টিউটর লগইন** — নিবন্ধনের সময় পাসওয়ার্ড দিলে টিউটর নিজে লগইন করে নিজের ফি, বিষয়, শ্রেণি, এলাকা, উপলব্ধতা ও পাসওয়ার্ড বদলাতে পারে (`tutor-login.html` → `tutor-dashboard.html`); লগইন হয় ফোন নম্বর + পাসওয়ার্ড দিয়ে, JWT টোকেন (৭ দিন) শুধু নিজের প্রোফাইলে কাজ করে। পাসওয়ার্ড bcrypt দিয়ে হ্যাশ করে রাখা হয়, কোথাও খোলা পাসওয়ার্ড সংরক্ষিত বা ফেরত দেওয়া হয় না
- **টিউশন অফার** — অভিভাবক/শিক্ষার্থীদের পোস্ট করা টিউশনির অফার: শিক্ষকের লিঙ্গ পছন্দ, পছন্দের বিভাগ, লোকেশন, শ্রেণি, বিষয়, শিক্ষার্থীর সংখ্যা, বেতন, সাপ্তাহিক রুটিন ও মিডিয়া ফিসহ কার্ড; বিষয়/শ্রেণি/এলাকা/বেতন/লিঙ্গ দিয়ে লাইভ ফিল্টার; বিস্তারিত দেখে আবেদনের নির্দেশনা (সিভি, অভিজ্ঞতা, স্টুডেন্ট আইডি কার্ড ও ফোন নম্বর)
- **অফার পোস্ট করা (শুধু অ্যাডমিন)** — নতুন টিউশনির অফার শুধু অ্যাডমিন প্যানেল থেকে পোস্ট করা যায় (অ্যাডমিন প্যানেল → অফারসমূহ → অফার যোগ করুন); সাধারণ দর্শকদের জন্য `post-offer.html` এখন শুধু একটি বিজ্ঞপ্তি পাতা
- **অ্যাডমিন প্যানেল** (`admin.html`) — সার্ভার-সাইড পাসকোড দিয়ে লগইন (পাসকোড শুধু সার্ভারের `ADMIN_PASSCODE` এনভায়রনমেন্ট ভ্যারিয়েবলে থাকে, কোডে বা পাতায় লেখা থাকে না); ড্যাশবোর্ডে মোট টিউটর/অফার/অনুরোধ ও খোলা অফারের পরিসংখ্যান এবং সাম্প্রতিক তালিকা; টিউটরদের উপলব্ধ/ব্যস্ত করা ও মুছে ফেলা; অফার যোগ করা, অফারের স্ট্যাটাস (খোলা/বন্ধ) বদলানো ও মুছে ফেলা; অনুরোধের স্ট্যাটাস (নতুন/যোগাযোগ হয়েছে/সম্পন্ন) বদলানো ও মুছে ফেলা। লেখা-মোছার API কলগুলোতে `x-admin-token` হেডার লাগে। ব্যাকএন্ড চালু থাকলে পরিবর্তন সার্ভারে (MongoDB-তে) সংরক্ষিত হয়।
- **বাংলা-প্রথম UI** — পুরো ইন্টারফেস বাংলায়, মোবাইল-বান্ধব ডিজাইন
- **অফলাইন ফলব্যাক** — ব্যাকএন্ড না চললে ফ্রন্টএন্ড localStorage ব্যবহার করে কাজ চালিয়ে যায়
- **MongoDB ডাটাবেইজ** — `MONGODB_URI` দিলে সব তথ্য MongoDB Atlas-এ সংরক্ষিত হয়; না দিলে JSON ফাইলেই কাজ চলে (নিচে দেখুন)

│   ├── request.html          # টিউটরের অনুরোধ ফর্ম

├── render.yaml               # Render-এ ব্যাকএন্ড হোস্ট করার ব্লুপ্রিন্ট (ফ্রি)
└── backend/                  # Node.js + Express API + MongoDB (Mongoose)
    ├── server.js             # REST API + ফ্রন্টএন্ড সার্ভ
    ├── db.js                 # MongoDB সংযোগ (ব্যর্থ হলে JSON ফলব্যাক)
    ├── models.js             # Tutor / Offer / Request স্কিমা
    ├── .env.example          # MONGODB_URI-এর নমুনা (আসল .env কখনো কমিট করবেন না)
    ├── scripts/
    │   └── seed-mongo.js     # JSON ফাইলের সিড তথ্য MongoDB-তে তোলার স্ক্রিপ্ট

## স্থানীয়ভাবে চালানো

```bash
cd backend
npm install
npm start
```

তারপর ব্রাউজারে খুলুন: http://localhost:3000

শুধু ফ্রন্টএন্ড দেখতে চাইলে `frontend/` ফোল্ডারটি যেকোনো স্ট্যাটিক সার্ভার দিয়ে চালান (তবে ফর্ম জমা দিতে ব্যাকএন্ড লাগবে; ব্যাকএন্ড ছাড়া তথ্য localStorage-এ সংরক্ষিত হয়)।

## MongoDB (Atlas) সেটআপ

ডিফল্টভাবে ব্যাকএন্ড JSON ফাইলে (`backend/data/*.json`) তথ্য সংরক্ষণ করে — কোনো সেটআপ ছাড়াই চলে। আসল ডাটাবেইজ ব্যবহার করতে:

1. **Atlas-এ ফ্রি ক্লাস্টার বানান** — [mongodb.com/atlas](https://www.mongodb.com/atlas) থেকে ফ্রি (M0) ক্লাস্টার তৈরি করুন।
2. **ডাটাবেইজ ইউজার বানান** — Atlas → Database Access → Add New Database User (পাসওয়ার্ডটি সংরক্ষণ করে রাখুন)।
3. **নেটওয়ার্ক অ্যাক্সেস দিন** — Atlas → Network Access → Add IP Address → **Allow Access from Anywhere** (`0.0.0.0/0`) (শুধু ডেভ/শুরুর জন্য)।
4. **কানেকশন স্ট্রিং নিন** — Atlas → Database → Connect → Drivers → কানেকশন স্ট্রিংটি কপি করুন।
5. **`.env` বানান** — `backend/.env.example` কপি করে `backend/.env` বানিয়ে `MONGODB_URI`-তে আসল স্ট্রিংটি বসান (ইউজারনেম ও পাসওয়ার্ডসহ)। `.env` কখনো গিটহাবে কমিট করবেন না — এটি `.gitignore`-এ আছে।
6. **সিড তথ্য তুলুন** — সার্ভারের JSON ফাইলের ৮ জন টিউটর, ৫টি অফার ও ৩টি অনুরোধ MongoDB-তে তুলতে:

```bash
cd backend
npm install
npm run seed:mongo
```

স্ক্রিপ্টটি শুধু খালি কালেকশনেই তথ্য ঢোকায় — দুইবার চালালেও ডুপ্লিকেট হয় না।

7. **সার্ভার চালান** — `npm start`। `MONGODB_URI` না থাকলে বা MongoDB-তে সংযোগ না হলে সার্ভার নিজে থেকেই JSON ফাইলে ফিরে যায়, ক্র্যাশ করে না। কোন স্টোরেজ চলছে তা দেখতে: `GET /api/health` — `"db": "mongo"` বা `"db": "json"`।

## ব্যাকএন্ড হোস্ট করা (Render, ফ্রি)

1. Render-এ (render.com) GitHub দিয়ে লগইন করে **New → Blueprint** দিয়ে এই রেপোটি নির্বাচন করুন — রেপোর `render.yaml` থেকে ফ্রি ওয়েব সার্ভিসটি তৈরি হবে।
2. Render ড্যাশবোর্ডে সার্ভিসটির **Environment** ট্যাবে `MONGODB_URI` ভ্যারিয়েবলে Atlas-এর কানেকশন স্ট্রিংটি বসান, আর `ADMIN_PASSCODE` ভ্যারিয়েবলে একটি শক্ত পাসকোড বসান (এটি ছাড়া লাইভ API-র লেখা-মোছা সবার জন্য খোলা থাকবে)। টিউটর লগইনের জন্য `JWT_SECRET` ভ্যারিয়েবলেও একটি লম্বা এলোমেলো স্ট্রিং বসান — না বসালে সার্ভার প্রতিবার রিস্টার্ট হলে টিউটরদের টোকেন অকার্যকর হয়ে যাবে।
3. ডেপ্লয় শেষে সার্ভিসের URL পাবেন, যেমন `https://tuition-platform.onrender.com` — সেটি `frontend/config.js` (ও `docs/config.js` — GitHub Pages-এর কপি)-এ `window.API_BASE`-এ বসিয়ে কমিট করুন, তাহলে লাইভ সাইটের ফর্মগুলো সরাসরি হোস্ট করা ব্যাকএন্ডে তথ্য পাঠাবে।

## API এন্ডপয়েন্ট

পড়া (GET) সবার জন্য খোলা। লেখা-মোছা — অফার পোস্ট করা, সব PATCH/DELETE — শুধু অ্যাডমিনের জন্য: অনুরোধে `x-admin-token` হেডারে `ADMIN_PASSCODE`-এর মান পাঠাতে হয়, না হলে `401 অননুমোদিত` আসে। ব্যতিক্রম: টিউটর নিবন্ধন (`POST /api/tutors`) ও টিউটরের অনুরোধ (`POST /api/requests`) পাবলিক ফর্ম, তাই সেগুলো খোলাই থাকে। লগইন: `POST /api/admin/login` (বডি: `{"passcode": "..."}`) — সঠিক হলে `{ok: true, token: "..."}` ফেরত দেয়। টিউটর লগইন: `POST /api/tutors/login` (বডি: `{"phone": "...", "password": "..."}`) — সঠিক হলে ৭ দিনের JWT দেয়; সেই টোকেন `Authorization: Bearer` হেডারে পাঠিয়ে টিউটর শুধু নিজের প্রোফাইল দেখতে (`GET /api/tutors/me`) ও বদলাতে (`PATCH /api/tutors/me` — ফি, উপলব্ধতা, বিষয়, শ্রেণি, এলাকা, নিজের সম্পর্কে, বিভাগ, বিশ্ববিদ্যালয়, এবং বর্তমান পাসওয়ার্ড যাচাই করে নতুন পাসওয়ার্ড) পারে। নাম, ফোন নম্বর বা অন্য টিউটরের তথ্য এই রুটে বদলানো যায় না।

| মেথড | পাথ | বিবরণ |
|------|-----|-------|
| GET | `/api/health` | সার্ভারের অবস্থা (`db`: `mongo` বা `json` — কোন স্টোরেজ চলছে) |
| POST | `/api/admin/login` | অ্যাডমিন লগইন — পাসকোড যাচাই করে টোকেন দেয় |
| GET | `/api/tutors` | সব টিউটর (ফিল্টার: `?subject=গণিত&class=HSC&area=ধানমন্ডি&maxFee=6000&q=বুয়েট`) |
| GET | `/api/tutors/me` | লগইন করা টিউটরের নিজের প্রোফাইল (JWT লাগে) |
| PATCH | `/api/tutors/me` | নিজের প্রোফাইল বদলানো (JWT লাগে) — ফি, উপলব্ধতা, বিষয়, শ্রেণি, এলাকা, নিজের সম্পর্কে, বিভাগ, বিশ্ববিদ্যালয়; `currentPassword` + `newPassword` দিলে পাসওয়ার্ড বদলায় |
| GET | `/api/tutors/:id` | একজন টিউটরের প্রোফাইল |

## অ্যাডমিন প্যানেল

`admin.html` খুলে পাসকোড দিয়ে ঢুকুন। পাসকোডটি সার্ভারের `ADMIN_PASSCODE` এনভায়রনমেন্ট ভ্যারিয়েবলে সেট করা থাকে (লোকালে `backend/.env`-এ, লাইভে Render ড্যাশবোর্ডে) — এটি কোডে বা পাতায় কোথাও লেখা থাকে না, আর প্যানেল থেকে বদলানো যায় না। লগইন করলে প্যানেল `POST /api/admin/login` দিয়ে পাসকোড সার্ভারে যাচাই করে; সফল হলে পাওয়া টোকেন শুধু ওই ট্যাবের sessionStorage-এ থাকে (ট্যাব বন্ধ করলে মুছে যায়)। লগইন অবস্থা রিফ্রেশ করলেও থাকে, ট্যাব বন্ধ করলে আবার পাসকোড চাইবে।

প্যানেলে আছে: পরিসংখ্যান ড্যাশবোর্ড, টিউটর/অফার/অনুরোধের তালিকা ও ব্যবস্থাপনা (দেখা, স্ট্যাটাস বদলানো, মুছে ফেলা) এবং অফারসমূহ ট্যাবে নতুন অফার যোগ করার ফর্ম।

**নিরাপত্তা সম্পর্কে সৎ কথা:** এটি একটি একক শেয়ার করা গোপন পাসকোড (shared secret), আলাদা ব্যবহারকারীর অ্যাকাউন্ট নয় — পাসকোড জানা যে কেউ অ্যাডমিন হতে পারবে। এটি লাইভ API-কে তখনই সুরক্ষা দেয় যখন Render-এ `ADMIN_PASSCODE` সেট করা থাকে; সেট না থাকলে সার্ভার লেখা উন্মুক্ত রাখে (শুধু লোকাল ডেভের জন্য) এবং স্টার্টআপে সতর্কবার্তা ছাপে। পাসকোডটি শক্ত করে বানান ও কারও সাথে শেয়ার করবেন না।

## টিউটর লগইন

নিবন্ধনের সময় পাসওয়ার্ড দিলে (ঐচ্ছিক, অন্তত ৬ অক্ষর) টিউটর পরে `tutor-login.html` থেকে ফোন নম্বর + পাসওয়ার্ড দিয়ে ঢুকে `tutor-dashboard.html`-এ নিজের ফি, বিষয়, শ্রেণি, এলাকা, উপলব্ধতা, নিজের সম্পর্কে, বিভাগ ও বিশ্ববিদ্যালয় বদলাতে পারে, আর বর্তমান পাসওয়ার্ড যাচাই করে নতুন পাসওয়ার্ড বসাতে পারে। নাম ও ফোন নম্বর নিজে বদলানো যায় না — সেগুলো বদলাতে অ্যাডমিনের সাথে যোগাযোগ করতে হয়।

কারিগরি কথা: পাসওয়ার্ড bcrypt দিয়ে হ্যাশ করে `passwordHash`-এ রাখা হয় — খোলা পাসওয়ার্ড কোথাও সংরক্ষিত বা কোনো API উত্তরে ফেরত দেওয়া হয় না (`GET /api/tutors`-এর তালিকাতেও নয়)। লগইনে সার্ভার ৭ দিনের JWT দেয়, যা শুধু ওই ট্যাবের sessionStorage-এ থাকে। টোকেন সই হয় `JWT_SECRET` এনভায়রনমেন্ট ভ্যারিয়েবল দিয়ে (লোকালে `backend/.env`-এ, লাইভে Render ড্যাশবোর্ডে) — সেট না থাকলে সার্ভার প্রতিবার চালুর সময় এলোমেলো গোপন কী বানায় আর স্টার্টআপে সতর্কবার্তা ছাপে, ফলে রিস্টার্টে সব টোকেন অকার্যকর হয়ে যায়।

**সিড টিউটরদের কথা:** শুরুতে দেওয়া ৮ জন সিড টিউটরের কোনো পাসওয়ার্ড নেই, তাই তারা লগইন করতে পারবে না — লগইন করতে চাইলে তাদের পাসওয়ার্ড দিয়ে আবার নিবন্ধন করতে হবে, অথবা অ্যাডমিন তাদের প্রোফাইল নতুন করে তৈরি করে দিতে পারে।

## Features (English)

- Tutor directory with live search & filters (subject, class, area, max fee)
- Tutor profile modal with education, experience, fee and reviews
- Student/parent request form and tutor registration form
- Tutor login: tutors who set a password at registration can log in with phone + password and manage their own fee, subjects, classes, areas, availability and password (JWT, 7 days, own profile only); passwords are bcrypt-hashed and never returned by the API
- Tuition offers: tuition jobs posted by the admin only (Admin panel → অফারসমূহ → অফার যোগ করুন) — teacher gender preference, preferred department, location, class, subjects, student count, salary, weekly schedule, media fee — with live filters and a detail view with application instructions; the old public post-offer page is now just a notice pointing visitors to the admin panel
- Admin panel (`admin.html`): server-side passcode login (passcode lives only in the `ADMIN_PASSCODE` env var, never in code or on the page), stats dashboard, add offers, manage tutors (available/busy toggle, delete), offers (open/close, delete) and requests (status, delete)
- Bengali-first, mobile-friendly UI; works with localStorage fallback when the API is down
- Node.js + Express backend with MongoDB (Mongoose) when `MONGODB_URI` is set, and JSON-file storage as a fallback when it is not; seed with `npm run seed:mongo`
